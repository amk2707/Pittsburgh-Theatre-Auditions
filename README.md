# Pittsburgh Stage Calls 🎭

A self-updating website that scrapes Pittsburgh theatre company websites for audition listings twice a week.

---

## File Structure

```
your-repo/
├── index.html               ← the website
├── scrape_auditions.py      ← the scraper
├── auditions.json           ← generated by the scraper (commit this too)
└── .github/
    └── workflows/
        └── scrape.yml       ← GitHub Actions schedule
```

---

## One-Time Setup (~ 10 minutes)

### 1. Create a GitHub repo

1. Go to [github.com](https://github.com) → **New repository**
2. Name it something like `pittsburgh-auditions`
3. Set it to **Public** (required for free GitHub Pages)
4. Click **Create repository**

### 2. Upload the files

Drag and drop all four files/folders into the repo via the GitHub web UI, **or** use git:

```bash
git init
git add .
git commit -m "initial commit"
git remote add origin https://github.com/YOUR_USERNAME/pittsburgh-auditions.git
git push -u origin main
```

### 3. Run the scraper once manually

In GitHub → **Actions** tab → **Scrape Pittsburgh Auditions** → **Run workflow**.

This creates `auditions.json` for the first time.

### 4. Enable GitHub Pages

1. GitHub repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `root`
4. Click **Save**

Your site will be live at:
`https://YOUR_USERNAME.github.io/pittsburgh-auditions/`

## How It Works

| Part | What it does |
|------|-------------|
| `scrape_auditions.py` | Fetches each theatre company's auditions page, extracts listings, saves to `auditions.json` |
| `scrape.yml` | GitHub Actions cron — runs the scraper every Monday & Thursday at 8am ET, commits updated JSON |
| `index.html` | Loads `auditions.json` on page open, renders the cards with filter buttons |

The scraper hits these sites:
- pittsburghclo.org
- pittsburghmusicals.com
- ppt.org (Pittsburgh Public Theater)
- primestage.com
- pbt.org (Pittsburgh Ballet Theatre)
- frontporchpgh.com
- pittsburghunifiedsauditions.com

## Running the Scraper Locally

```bash
pip install requests beautifulsoup4
python scrape_auditions.py
```

Open `index.html` in your browser (via a local server — e.g. `python -m http.server`).

## Adding More Theatre Companies

Open `scrape_auditions.py` and add a new function following the same pattern:

```python
def scrape_my_new_theatre() -> list[dict]:
    soup = fetch("https://example.com/auditions")
    if not soup:
        return []
    # ... parse and return list of dicts
    return [{ "show": "...", "company": "...", ... }]
```

Then add it to the `SCRAPERS` list at the bottom of the file.

---

## Changing the Scrape Schedule

Edit `.github/workflows/scrape.yml` — the `cron` line uses standard cron syntax (UTC time):

```yaml
- cron: "0 12 * * 1,4"   # Mon & Thu at 8am ET (noon UTC)
```

Use [crontab.guru](https://crontab.guru) to build a custom schedule.
